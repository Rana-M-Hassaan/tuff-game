
Catch the Thief

This is a simple 2D game I made using the p5.js library in JavaScript. It runs on regular canvas coordinates and uses basic tracking variables to handle the workflow of the game loops
This Game has the following features:
- Built fully inside the p5.js library setup
- Uses millisecond timing system for tracking the clock countdown
-Regular shape loops like ellipse and rect for drawing the layout blocks
- Simple distance math check for mouse clicks on the canvas

Rules to play:
1. Click the screen layout to start the match up.
2. Try to click on the black thief silhouette before the 30 second timer runs out. Catching it gives you +1 score point and teleports it.
3. Dont click the red enemy character or it subtracts -2 score points from your current total instead.
4. Try to get the highest score possible before the main timer hits zero
